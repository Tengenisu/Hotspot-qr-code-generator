# 📶 Hotspot QR Code Generator

The **Hotspot QR Code Generator** is a Python-based desktop application that allows users to create QR codes for Wi-Fi hotspot connections. This makes sharing Wi-Fi credentials easier, faster, and more secure — no more manually typing passwords!


## 🚀 Features

- ✅ Simple and intuitive Tkinter GUI
- 🔐 Supports major encryption types (WPA/WPA2/WPA3/WEP/None)
- 📷 Instantly generate QR codes for hotspot credentials
- 📱 Scan the code with a mobile device to auto-connect to the Wi-Fi
- ⚠️ Input validation to ensure required fields are filled

---

## 🛠️ Technologies Used

- **Python 3.13**
- **Tkinter / ttk** – for building the GUI
- **qrcode** – for generating the QR code
- **Pillow (PIL)** – to render the QR image in the interface
